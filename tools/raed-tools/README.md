# raed-tools

أدوات رائد شهاب داخل Claude Code. أوامر قوالب تعمل محليًا ولا تستهلك من رصيدك، ومراقب يعرض نسبة امتلاء السياق وحدود الاستخدام بعد كل رد، وينبّهك عند 70% لتكتب /compact.

Commands: /raed-help, /raed7, /mashhad, /flow, /nashr, /usage — templates shown locally with zero model tokens, plus a status-line usage watcher.

Install: `/plugin install raed-tools --marketplace <owner>/<repo>`
