# الأدوات والتكلفة
إعداد: 2026-10-07. هذه خريطة عمل، وليست مقارنة أسعار أو إثبات اشتراكات.

| المرحلة | خيار العمل | المطلوب قبل التنفيذ |
|---|---|---|
| الفكرة والنص | إعداد الحزمة هنا | مصادر رسمية للحقائق |
| التصوير | الهاتف وميكروفون متاح | اختبار الضوء والريح والتخزين |
| التوليد الاختياري | Google Flow أو أداة يختارها رائد | تحقق من الطراز والرصيد وتسعير الحساب |
| الصوت | تسجيل رائد أو أداة صوت يختارها | اختبار الاسم السويدي والالتزام بالنص |
| المونتاج | محرر متاح مثل CapCut | تحقق من الميزات المتاحة وترخيص الموسيقى |
| النشر | حسابات رائد | مراجعة وموافقة صريحة |

## نموذج تقدير التوليد
الأداة / الطراز / الدقة / مدة المشهد / تكلفة المشهد / عدد المشاهد / إعادة المحاولة / المجموع / تاريخ التحقق.
كل خانة غير متحققة تظل «غير متحقق»، ولا تتحول إلى صفر.

## حالة حزمة Skärholmen
لم يتم توليد صورة أو فيديو أو صوت؛ لم يُفحص رصيد حساب.
التصوير بالهاتف لا يحتاج كريدت توليد. نفقات التنقل والاشتراكات المحتملة غير محسوبة.
اختبار Flow المقترح: المشهد 1 فقط، بعد عرض تكلفة الحساب والموافقة.
