## قاعدة التحديث

1. احفظ النص الجديد مستقلًا، وقارنه بالمرجع المختص قبل تغيير مؤشر الأحدث.
2. لا تخلط إصدار التطبيق بإصدار دليل المدن أو دليل المشاريع.
3. حدّث catalog.json ودليل Notion وروابط الواجهة في التحديث نفسه، مع تاريخ وحالة تنفيذ.
4. مع كل دليل: الهدف، الجمهور، المدخلات، المخرجات، الإصدار، الحالة، المصدر، وحدود الاستخدام.
5. الإضافات تُرقم إضافة 01 و02…، ويبقى اسم RAED7 ما دام المنهج سبع مراحل.
6. لا توصف أي مادة بأنها مولّدة أو مختبرة أو منشورة إلا بدليل تنفيذ.
