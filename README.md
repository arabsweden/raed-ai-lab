# RAED AI LAB | مختبر رائد

مكتبة رائد شهاب لحفظ وتنظيم برومبتات الذكاء الاصطناعي وسكربتات الفيديو وأدلة صناعة المحتوى.

## مراحل RAED7
1. الفكرة
2. السكربت
3. مخطط المشاهد
4. الصور المرجعية
5. الصوت
6. المونتاج
7. النشر

## أقسام المكتبة
- برومبتات Google Flow
- سلسلة مدن السويد
- جولات Stockholm Guide
- تثبيت الوجه والهوية
- حركات الكاميرا والإضاءة والمؤثرات
- نصوص المنشورات والعناوين والصور المصغرة

## قواعد الإنتاج
- الحفاظ الدقيق على ملامح الشخص في الصورة المرجعية.
- فيديوهات عمودية 9:16، إلا عند طلب مقاس آخر.
- تحديد مدة كل مشهد والصور المرجعية المطلوبة.
- ضبط النص العربي والتشكيل عند إعداد التعليق الصوتي.
- كتابة أسماء الأشخاص والأماكن بلغتها الأصلية، وتوجيه الصوت لنطقها بتلك اللغة.
- عدم وضع نص عربي على الشاشة في فيديوهات Google Flow.
- تضمين هوك واضح ودعوة للتفاعل.
