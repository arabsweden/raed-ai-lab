# قواعد إنتاج RAED AI LAB
تاريخ الإعداد: 2026-10-07

## RAED7
الفكرة → النص → المشاهد → الصور المرجعية → الصوت → المونتاج → النشر.
لكل مشروع مجلد مستقل. لا تختلط أخبار عرب السويد بمحتوى Familjebron أو Stockholm Guide.

## الصورة والتصوير
- الافتراضي 9:16، ومشاهد 8–10 ثوانٍ.
- هوك في أول 3 ثوانٍ، اكتشاف واضح، دعوة تفاعل واحدة.
- حركة كاميرا رئيسية واحدة لكل لقطة؛ تغيير أحجام اللقطات بين المشاهد.
- الصورة المرجعية أساس الهوية: حافظ على العمر والوجه والبشرة والشعر والنسب دون تجميل زائد. افحص الناتج؛ لا تعد بثبات مثالي.
- الصور المرجعية المذكورة في الملفات ليست مرفوعة تلقائيًا إلى GitHub. اربط الأصول الموجودة بدل تكرارها.

## الصوت — قاعدة إلزامية
- صوت عربي ثابت وواضح؛ الأردنية للشخصي والفصحى للرسمي.
- كتابة أسماء الأماكن والأشخاص بلغتها الأصلية ونطقها بلغتها الأصلية.
- لا تستبدل Skärholmen أو غيره بتهجئة عربية في النص المعتمد.
- اقرأ النص حرفيًا: لا تكرر حرفًا أو كلمة، لا تضف كلمات أو أصواتًا كلامية، لا تحذف أو تعيد صياغة.
- تعليمات النطق ليست حوارًا: لا يقرأ الراوي عبارة «لفظ الاسم باللغة السويدية».
- إذا أخفق نطق الاسم، سجّله وحده باللغة الأصلية وادمجه؛ راجع الجملة بعد الدمج.
- لا يوجد تسجيل صوتي معتمد قبل الاستماع الفعلي إليه ومقارنته بالنص.

## النص والمونتاج
- لا نص عربي داخل الفيديو إلا بطلب صريح؛ أسماء الأماكن بلغتها الأصلية أعلى الكادر بعيدًا عن الوجه.
- لا اسم صاحب القناة داخل برومبتات Flow.
- أضف RAED SHIHAB في المونتاج النهائي.
- عند استخدام صور أو لقطات مولدة، أضف تنويه AI-generated visuals في المونتاج؛ الفيديو الحقيقي فقط لا يُوصف بأنه مولد.
- أضف المؤثرات مع الحدث وخفّض الموسيقى تحت الصوت. استخدم موسيقى مرخصة للمنصة.

## الدقة والتكلفة
- وثّق المصادر وتاريخ التحقق؛ ميّز الوقائع عن اقتراحات التصوير.
- لا تخمّن رصيد الحساب أو أسعار التوليد. تحقق من الأداة والطراز قبل عرض التكلفة.
- اعرض التكلفة واطلب موافقة التوليد المدفوع، ثم اختبر مشهدًا واحدًا.
- حفظ الحزمة لا يعني إنتاج الفيديو أو اعتماد الصوت أو النشر.
- موافقة صريحة قبل نشر المحتوى للجمهور أو إرسال رسائل.
